# Work calendar

The work-hour rules in [team task standards](team-task-standards.md), section 4, are authoritative. Use `Asia/Shanghai` and exclude the required 12:00–13:30 lunch break from planned and actual work-hour totals. Use explicit conversation or saved project/user calendar settings for shift times, weekends, and holidays; never invent a shift.

For clock-time estimates, round the current Beijing time down to a whole hour and calculate backwards across configured work segments. If CLI fields only store dates, keep exact intervals in the confirmation conversation and do not claim ZenTao stores clock-time precision. Actual work times must be verified; do not copy planned intervals into actual fields without the user's confirmation.
